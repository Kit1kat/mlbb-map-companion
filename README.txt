MLBB MAP COMPANION — MVP ДЛЯ iPHONE

Это веб-приложение (PWA), а не установленный App Store IPA.
Оно работает в Safari и может быть добавлено на экран «Домой».

КАК ЗАПУСТИТЬ:
1. Разместите содержимое папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте опубликованный адрес в Safari на iPhone.
3. Нажмите «Поделиться» -> «На экран Домой» -> «Добавить».
4. Запустите с иконки на домашнем экране.

Важно:
- Для Service Worker и установки PWA нужен HTTPS (или localhost).
- Карта схематичная, отметки ставятся вручную.
- Таймеры настраиваемые и не утверждают актуальные игровые интервалы.
- Приложение не подключается к игре, не читает память игры и не раскрывает скрытых врагов.
